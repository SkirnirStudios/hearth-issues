# Hearth: playtest reports

This repository is only for reporting bugs and sharing feedback on **Hearth**, the browser game from Skirnir Studios,
during its playtest (**Alpha 0.3**). The game's code is not here.

- **Play the alpha:** <https://hearth.skirnirstudios.com/>
- **About the game:** <https://skirnirstudios.com/hearth/>

## Reporting a bug

[Open a new issue](https://github.com/SkirnirStudios/hearth-issues/issues/new/choose) and pick **Bug report**. What helps
most:

- what happened, and what you expected;
- the year and day in the valley, and what you were doing;
- your browser and device;
- a save, if you can: the ☰ menu's **Saved valleys** panel can download a `.hearth` file, which you can attach.

Hearth is an early demo: things will change and some will break. Saves live in your own browser and may not carry over
between alpha versions. You need a free GitHub account to open an issue.
